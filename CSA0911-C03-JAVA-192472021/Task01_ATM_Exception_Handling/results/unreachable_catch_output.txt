--- Correct Catch Block Hierarchy (Narrower to Broader) ---
[Handled by specific subclass]: FileNotFoundException caught.

--- Why Broader Before Narrower Fails To Compile ---
If we write the following code in Java:
    try {
        simulateError();
    } catch (Exception e) {          // Superclass catch
        System.out.println("Generic");
    } catch (FileNotFoundException fnf) { // Subclass catch - UNREACHABLE!
        System.out.println("Specific");
    }

Compiler Error generated by javac:
    error: exception FileNotFoundException has already been caught
Reason: Any FileNotFoundException object is an instance of Exception.
The JVM matches catch clauses top-to-bottom. The first block will match
every instance, making the second block completely dead (unreachable) code.
